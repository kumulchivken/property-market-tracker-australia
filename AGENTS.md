# Repository instructions for coding agents

- Read `BUILD_PROMPT.md` before implementing or changing the application.
- Keep this repository private. Do not publish the site publicly or change repository visibility without the owner's explicit request.
- Treat addresses, portfolio values, and other financial details as sensitive personal data. Never put real values in fixtures, URLs, telemetry, screenshots, commits, or logs.
- Never fabricate or scrape address-level prices. Mark unavailable data as stale or insufficient; allow only user-entered or properly licensed data.
- Show the source, reference period, release date, and retrieval time for economic series. Do not label release-lagged statistics as real-time.
- Label property-cycle clock positions as estimates and show their evidence, methodology, as-of date, and confidence.
- Do not commit credentials, tokens, `.env` files, or private user data. Use server-side secret storage.
- Preserve historical observations when archiving a property. Confirm destructive data deletion.
- Before delivery, summarize implemented features, data limitations, privacy controls, checks run, and deployment status.
